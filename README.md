# Шкільні розширення для Chrome

Набір розширень Google Chrome для роботи з електронним журналом шкіл на платформі `*.academy.com.ua`.
Розширення працюють лише у вашому браузері, використовують вашу поточну сесію на сайті школи
і **нічого нікуди не надсилають**.

## Розширення

| Розширення | Що робить | Завантажити |
|---|---|---|
| [Експорт журналів](extensions/journal-export/) | Вивантажує журнали вчителя (оцінки, «Н», коментарі, теми, ДЗ) з 1 вересня по сьогодні в Excel | [journal-export.zip](https://github.com/VladislavSournine/SchoolChromeExt/releases/latest/download/journal-export.zip) |

## Як встановити (≈2 хвилини)

Розширення не з Chrome Web Store, тому його встановлюють вручну, як «розпаковане».

### 1. Завантажте і розпакуйте
1. Натисніть посилання **«Завантажити»** в таблиці вище — скачається `.zip`-файл.
2. Відкрийте папку «Завантаження» і розпакуйте архів (на Windows: правою кнопкою → **«Видобути все…»**;
   на Mac: двічі клацніть на файлі).
3. З'явиться папка, наприклад `journal-export`. **Перенесіть її в постійне місце**
   (наприклад, у «Документи»): Chrome бере розширення саме з цієї папки, тож не видаляйте й не переміщуйте її після встановлення.

### 2. Додайте в Chrome
1. В адресному рядку Chrome введіть `chrome://extensions` і натисніть Enter.
2. Справа вгорі увімкніть перемикач **«Режим розробника»** (Developer mode).
3. Натисніть кнопку **«Завантажити розпаковане розширення»** (Load unpacked) зліва вгорі.
4. Виберіть розпаковану папку (`journal-export`), ту, всередині якої лежить файл `manifest.json`.
5. Розширення з'явиться у списку. За бажанням натисніть значок пазла 🧩 праворуч від адресного рядка
   і закріпіть його.

### 3. Перевірте
Відкрийте (або оновіть, F5) сайт своєї школи й увійдіть. Справа внизу має з'явитися кнопка розширення.
Як ним користуватися, описано в README кожного розширення (посилання в таблиці).

## Оновлення до нової версії
1. Скачайте свіжий `.zip` за тим самим посиланням.
2. Розпакуйте його і **замініть вміст старої папки** новим (там само, де вона лежала).
3. На `chrome://extensions` натисніть значок оновлення ⟳ на картці розширення й оновіть сторінку сайту.

## Видалення
`chrome://extensions` → **«Вилучити»** на картці розширення. Після цього папку можна видалити.

## Часті питання
- **Chrome пише «Вимкніть розширення в режимі розробника»**: це звичайне попередження для розширень не з Web Store.
  Натисніть «Закрити» або «Скасувати», розширення працюватиме далі.
- **«Маніфест відсутній або нечитабельний»**: ви вибрали не ту папку. Потрібна та, де всередині одразу видно `manifest.json`
  (іноді після розпакування виходить папка в папці).
- **Кнопка не з'являється**: переконайтеся, що розширення увімкнене на `chrome://extensions`, і оновіть сторінку сайту (F5).
- **Працює в Edge / Brave / Opera?** Так, це браузери на основі Chromium; сторінка розширень у них: `edge://extensions` тощо.

## Для розробників

```
extensions/
  <назва>/            # одне розширення = одна папка
    manifest.json
    src/              # код, що потрапляє в zip
    tests/            # node --test, у zip не потрапляє
    docs/             # дизайн/контракт, у zip не потрапляє
    README.md         # інструкція для користувача
scripts/build-zips.sh # пакує кожне розширення в dist/<назва>.zip
```

**Нове розширення:** створіть `extensions/<назва>/` з `manifest.json` і додайте рядок у таблицю вище
з посиланням `https://github.com/VladislavSournine/SchoolChromeExt/releases/latest/download/<назва>.zip`.

**Тести:** `cd extensions/<назва> && node --test tests/*.test.js`

**Реліз:**
```bash
./scripts/build-zips.sh
gh release create vX.Y.Z dist/*.zip --title "vX.Y.Z" --notes "Що змінилось"
```
Посилання `releases/latest/download/<назва>.zip` завжди веде на останній реліз, тож README оновлювати не треба.
