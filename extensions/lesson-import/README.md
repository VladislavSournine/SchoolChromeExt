# Уроки в журнал A+ (aik.academy.com.ua)

Розширення Chrome, яке заповнює електронний журнал з папки тижня: **тему уроку, файли уроку (PDF),
домашнє завдання і файли ДЗ**. Працює на сторінці «Розклад вчителя» `aik.academy.com.ua`, використовує
вашу поточну сесію, нічого нікуди не надсилає.

**Заповнене не перезаписує.** Кожне поле пишеться лише якщо воно порожнє; стан уроку перечитується з порталу
прямо перед записом, а після запису — перевіряється.

## Встановлення
Завантажте [lesson-import.zip](https://github.com/VladislavSournine/SchoolChromeExt/releases/latest/download/lesson-import.zip)
і встановіть його за [покроковою інструкцією](../../README.md#як-встановити-2-хвилини).

## Використання
1. Відкрийте **Розклад вчителя**. Праворуч унизу — синя кнопка **«Уроки з папки»**.
2. **«Обрати папку тижня»** → папка з `uroky.json` (напр. `~/Downloads/02.11–06.11`). Chrome попросить дозволу
   переглянути файли — погодьтеся.
3. Таблиця перевірки: зелений «+» — поле буде заповнене, сіре «вже є — пропуск» — не чіпається,
   «—» — для цього поля в `uroky.json` нічого немає, червоний рядок — помилка, з нього нічого не вантажиться.
4. Залиште галочки потрібним рядкам → **«Завантажити вибрані»** → ще раз для підтвердження.
5. Унизу — журнал дій; «перевірено ✓» означає, що все збереглося.

## Формат папки тижня
```
02.11–06.11/
  4 Четвер 05.11/<презентація>.pdf, <роздатка>.pdf
  uroky.json
```
`uroky.json` — масив уроків:
```json
{"data": "2026-11-05", "klas_id": 64, "klas": "10IT", "predmet_id": 171, "predmet": "…",
 "tema": "…", "fayly_uroku": ["4 Четвер 05.11/….pdf"], "dz": "текст ДЗ", "fayly_dz": []}
```
Шляхи у `fayly_*` — відносно папки тижня. Урок шукається за `klas_id`/`predmet_id` з адреси журналу
(`/journal/<клас>/<предмет>/<дата>/…`), не за назвою. Порожній `fayly_dz` — поле «Файли ДЗ» не чіпається.

## Розробка
Код — `src/content.js`, одна IIFE без залежностей. Перевірка синтаксису: `node --check src/content.js`.
